【产品性能】球拍套采用厚实的氯丁橡胶材料制成，能有效保护您的球拍免受碎片、咬伤和刮擦，使您的设备保持更长时间的新状态，并保持更好的性能。前面有一个网袋，可以存放你的匹克球、毛巾、头带、腕带等。长拉链可打开至匹克球包的顶部，使穿脱变得简单，且氯丁橡胶材料具有轻微弹性，适合大多数匹克球拍。非常适合携带匹克球拍，可将其挂在运动包、背包和斜挎包上。
