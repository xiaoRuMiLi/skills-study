# 《巴菲特之道》第4章：普通股投资9个案例

> 12准则的实战演示。每个案例都是独一无二的背景，但共同点：让我们观察现实中的企业状况、管理、财务和市场准则如何被运用。

九个案例：华盛顿邮报、盖可保险、大都会/ABC、可口可乐、通用动力、富国银行、美国运通、IBM、亨氏食品。除大都会外都仍在伯克希尔组合中；除华盛顿邮报和通用动力外都进过伯克希尔前十大持仓。

## 案例1：华盛顿邮报公司（1973）——安全边际的教科书

- **背景**：1931年尤金·迈耶82.5万美元拍卖买下；后发展为报纸+杂志（《新闻周刊》）+电视台的多元化媒体公司。凯瑟琳·格雷厄姆1963年接班，1971年上市。
- **买入**：1973年市场大跌中，巴菲特以22.75美元均价买入467,150股，耗资1062.8万美元。当时公司总市值8000万美元，而"大部分证券分析师、媒体经纪人、媒体执行层都将公司估值为4~5亿美元"。
- **估值过程（12准则·市场准则示范）**：
  - 1973年股东盈余 = 净利润1330万 + 折旧摊销370万 − 资本支出660万 = 1040万美元；
  - 用长期国债利率6.81%折现 → 1.5亿美元（已近市值两倍）；
  - 报纸资本支出长期≈折旧摊销，净利润≈股东盈余 → 估值1.96亿美元；
  - 报纸业在当地垄断地位→提价能力超过通胀3% → 估值3.5亿美元；
  - 凯瑟琳领导下税前利润率若从10%恢复历史均值15% → 估值4.85亿美元。
- **结论**：即使最保守计算也是半价买入，巴菲特自己认为实际是**2.5折**。
- **准则对照**：简单易懂（巴菲特送过邮报、拥有《奥马哈太阳报》四年经验）；特许经营权（"拥有了一家报纸，就可以收取城里每一个想做广告的企业的版权费"）；管理层（凯瑟琳+巴菲特任财务委员会主席，投票权委托给唐·格雷厄姆）；财务（ROE从15.7%到1988年36%；负债权益比从37%降到2.7%）；资本配置（1975-1991年以均价60美元回购43%股份；1990年分红提高117%）。
- **教训**：以巨大折扣买入能创造安全边际——格雷厄姆的前提条件被完美满足。

## 案例2：盖可保险公司（GEICO）——危机中的低成本堡垒

- **模式**：1936年成立，直销汽车保险（不经保险代理）→ 结构性低成本优势；只承保谨慎驾驶者。
- **危机**：70年代脱离传统方法，降低投保人准入标准+放松成本控制→拨备不足+固定成本上升，1976年濒临破产。
- **巴菲特的行动**：1976年开始买入（早年格雷厄姆-纽曼公司曾是股东，巴菲特1951年就研究过它——他在哥伦比亚大学的老师格雷厄姆是盖可董事长）。判断核心：公司困境是**管理偏差**，而非**商业模式损坏**——低成本护城河仍在，需要的是回归本源的经理人（杰克·伯恩）。
- **验证**：1977-1992年盖可综合比率平均97.1%，比行业平均水平低十个百分点（行业仅1977年胜过盖可一次）。
- **结局**：1996年伯克希尔全资收购盖可。

## 案例3：大都会/ABC公司（Capital Cities/ABC）——为管理层付溢价

- **核心资产是人**：汤姆·墨菲和丹·伯克——巴菲特眼中最优秀的管理层组合。理性（资本配置大师）、坦诚、抗拒惯性驱使、"痛恨乱花钱"。
- **交易**：1985年巴菲特注资5亿美元，帮助大都会收购美国广播公司（ABC）。
- **准则对照**：管理层准则是本案例的决定性因素——巴菲特甚至将投票权委托给管理层，以示信任。大都会式管理：去中心化运营+高度集中的资本配置；大手笔回购；严格控制成本。
- **教训**："与坏人打交道做成一笔好生意，我们从来没有遇见过"的正面表述——遇到顶级管理层，值得以合理价格支持。

## 案例4：可口可乐公司（1988）——特许经营权的标准像

- **渊源**：巴菲特5岁第一次喝可乐，童年花25美分批发六罐再以5美分一罐卖出。目睹其成长50年却没买——直到1988年夏天开始买入，投下10亿美元。
- **买入逻辑**：①特许经营权教科书——被渴望、无可替代、无管制；②全球扩张的成长空间（"一个伟大企业的定义至少是伟大25~30年"）；③管理层戈伊苏埃塔的理性资本配置（聚焦核心业务、回购股票）。
- **教训**：好公司就在那里半个世纪，问题是你什么时候看懂它、什么时候价格合适。**能力圈+耐心**的交汇点才是买点。

## 案例5：通用动力公司（General Dynamics）——资本配置创造价值

- **背景**：军工企业，1990年美国第二大国防承包商（导弹、防空、航天、F-16）。1990年营收100亿美元，1993年降到35亿美元——但**同期股东价值上升7倍**。
- **逻辑**：冷战结束军工萎缩，管理层（比尔·安德斯）理性应对：收缩业务、出售非核心资产、把现金还给股东（回购+特别分红），而不是多元化乱并购。
- **教训**：营收下降≠价值毁灭。**理性的资本配置在收缩行业中反而能创造巨大股东价值**——管理准则"理性"的最佳反面行业案例。

## 案例6：富国银行（1990）——在恐惧中买入

- **背景**：1990年加州房地产危机恐慌，银行股被抛售。巴菲特买入富国银行。
- **逻辑**：①银行业是"普通商品"生意，但富国是**低成本供给者**（普通商品型企业唯一可靠的赚钱方法）；②管理层卡尔·赖卡特和保罗·黑曾是成本控制大师（"痛恨乱花钱"二人组）；③市场把"房地产风险"过度定价——实际损失远没有股价反映的严重。
- **教训**：别人恐惧时贪婪的前提，是你比市场更懂这家企业的真实资产质量和成本结构。

## 案例7：美国运通——护城河+危机反转（两次）

- **第一次（1964）**：色拉油丑闻危机，市场恐慌抛售。巴菲特判断：运通的护城河是**品牌信任与网络效应**，丑闻不伤根基。投入合伙企业40%资金——集中投资的早期经典。
- **第二次（1990年代）**：竞争压力下再度受挫后买入。
- **教训**：伟大企业遭遇可修复的危机时，是市场先生送礼的时刻。判断关键：危机伤的是**利润表**（可修复）还是**护城河**（不可修复）。

## 案例8：IBM（2011）——能力圈的晚期扩张

- **意外之处**：巴菲特几十年不碰科技股，2011年却大举买入IBM。
- **逻辑**：IBM已不是硬件公司——郭士纳时代转向咨询和软件，彭明盛时代摆脱低利润普通商品化业务，转向高利润、有护城河性质的咨询、系统集成、IT外包。ROE：1994年14% → 2002年35% → 2012年62%。加上持续大额回购（提升每股内在价值）。
- **教训**：能力圈可以学习扩大；护城河存在于**客户转换成本**而非技术炫酷度。

## 案例9：亨氏食品（2013）——与3G资本的合作

- **交易**：伯克希尔联合巴西3G资本收购亨氏（番茄酱全球第一、酱菜类第二）。
- **逻辑**：①品牌特许经营权（人们永远会用劳动价值换一罐番茄酱）；②新兴市场成长空间（销售额前十大市场中7个是新兴市场；2010年收购福达中国后价值翻倍）；③3G资本负责运营（成本削减大师），伯克希尔主要出资——角色分工各展所长。
- **教训**：晚期巴菲特的模式演化——与优秀运营者合伙，自己做资本提供者。

## 跨案例的共同模式

| 模式 | 案例 |
|------|------|
| 危机/恐慌中买入伟大企业 | 盖可、美国运通、富国银行 |
| 特许经营权+长期持有 | 可口可乐、华盛顿邮报、亨氏 |
| 押注顶级管理层 | 大都会/ABC、通用动力 |
| 能力圈扩张后的出手 | IBM（科技）、亨氏（新合伙模式） |
| 巨大安全边际 | 华盛顿邮报（2.5折） |

**共同分母**：简单易懂 + 护城河 + 理性坦诚的管理层 + 真实的股东盈余 + 折扣价。12准则不是抽象原则，是每一笔交易都被反复验证的清单。
