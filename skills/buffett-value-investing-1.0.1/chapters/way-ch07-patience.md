# 《巴菲特之道》第7章：耐心的价值

> 列夫·托尔斯泰《战争与和平》："天下勇士中，最为强大者莫过于两个——时间和耐心。"

## 时间坐标：投机与投资的真正分界

- 所有市场行为都分布在时间坐标上：微秒、分、小时、天、星期、月、年、十年。**越靠左越是投机，越靠右越是投资**。巴菲特悠闲安静地坐在坐标右侧，保持长期耐心。
- 为什么多数人挤在左侧？贪婪、错误信念（以为能预测市场心理）、经历熊市后对长期投资失去信心——答案全都是"Yes"。

## 学术证据：短期对冲 vs 长期投资

- 哈佛教授安德烈·施莱弗与芝加哥大学教授罗伯特·维什尼（1990年《美国经济评论》）：比较成本、风险、短期与长期对冲回报。
  - 对冲的成本 = 投入资本的时间价值；风险 = 结果的不确定性；回报 = 投资盈利。
  - 短期对冲：三要素都小→回报也少，必须一次又一次重复迅速行动才能提高回报；
  - 长期对冲：资本投入期长、回报更不确定，但**回报必须更高**才能取得平衡——"长期对冲投资策略必须从更为严重的错误定价中获取更多回报"。
- 控制变量只有一个：**时间跨度**。投机者期望时间短些哪怕回报少些；投资者期望时间长些同时回报更高。

## 长期持有的数据证据

- 研究结论：长期而言，买入并持有股票能获得更大回报——"除非你认为每五年翻一番实在太过平凡，这相当于14.9%的年复利回报率"。
- **1950~1970年，市场平均持股时间为4~8年；70年代起持续缩短，如今基金持股时间以月计算。**
- 关键发现：**获取超额收益的机会通常出现在持股三年之后**。换手率超100%的绝大多数人与此无缘。

## 磁石效应：为什么超额回报留给长期投资者

- 市场本该自我调节：一半力量吸引短期炒家纠正错误定价，一半力量吸引长期投资者填平价格-价值差距。
- 现实是人们从长期投资转向短期投机——因为短期投机参与者太多，胜出难度增加、回报减少；强有力的**磁石效应**吸引越来越多的人参与短期投机，把稀有的超额回报机会留给了长期投资者。
- 43年跨度里，价格与价值的差距依旧存在——"那些预期中的、消灭错误定价的长期投资者大军总是缺席的。"

## "慢速"的价值

- 两种投资观点：①简单明了、几乎不要求特殊技能就能评估→迅速决策；②要求反馈、判断、特殊专业技能→慢速决策。
- 巴菲特的方式显然是后者：花大量时间阅读、思考、等待，出手极少但极重。

## 实战启示

1. 重新定义"长期"：不是套住了死拿，而是**主动选择在3年以上的时间尺度上让企业价值兑现**。
2. 耐心的本质是对企业基本面的信念——没有研究的"耐心"只是固执，有研究的耐心才是策略。
3. 自检：你过去一年的换手率是多少？如果超过100%，你实际上是个投机者，不管你怎么称呼自己。
4. 耐心的配套动作：少看盘（对抗短视）、多读书年报（深化信念）、预留现金（等得起才能买得狠）。
