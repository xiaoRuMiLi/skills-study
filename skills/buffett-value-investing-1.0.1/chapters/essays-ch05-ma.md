# 《致股东的信》第5章：兼并与收购

> "我亲吻了它们，但它们一样还是呱呱叫的癞蛤蟆。"——巴菲特早年也付过学费。本章是他对并购狂热的系统批判，以及伯克希尔式收购的纪律。

## A. 错误的动机和高昂的代价

- 童话开场：公主吻了癞蛤蟆变王子。管理层深信自己的"管理之吻"能为被收购公司创造奇迹——"我们观察到很多吻，但很少奇迹。"
- **高价收购的三个通常不明说的原因**：
  1. **动物精神**：管理层（尤其买方）天生喜欢行动和兴奋——"收购令人心跳加速，平淡无奇的日常经营做不到这一点"；
  2. **规模渴望**：大多数组织和个人的地位与规模挂钩，不与孩子数量为参考（"越大越有面子"）；
  3. **过度乐观**：管理层高估自己创造奇迹的能力（对协同效应的系统性高估）。
- **买家用股票支付时的隐形陷阱**：如果买家股票市价只有内在价值的一半，用它去收购=用50美分的货币付1美元的账——"使用被大大低估的股票去进行收购"是双重灾难（买贵了+贱卖了自己）。讽刺的是：同一家公司整体出售时会坚持要足价，发行股票收购时却只能按市价打折。
- 会计把戏：并购会计（如权益结合法时代的处理）可以制造"盈利增长"幻觉，协同效应停留在PPT上。

## B. 合理的股票回购 vs 绿色邮件讹诈式回购

- 合理回购：价格/价值性价比成立时，回购是最好的资本用途之一。
- **绿色邮件（greenmail）批判**：敌意收购者买入股份后，讹诈公司高价回购其持股以换取退场——巴菲特视之为用全体股东的钱向讹诈者交赎金，坚决拒绝参与。"我们对于收购的背书仅限于价格/价值所形成的性价比关系，并没有延伸至讹诈式绿色邮件。"

## C. 杠杆收购（LBO）

- LBO的三宗罪：①收购价格由债务能力而非企业价值决定；②收购后的企业被压上高杠杆，失去应对逆境的弹性；③PE玩家的盈利来自"倒买倒卖"的估值游戏（用现金流指标包装），而非经营改善。
- 巴菲特的判断：大量LBO在利率正常化或经济放缓时崩解——"当盈利不足以覆盖一个垃圾债券的利率……使用现金流（指标）是最方便的（包装手法）。"

## D. 稳定的收购政策

伯克希尔的收购标准（公开发布的"收购启事"）：
1. 大买卖（规模门槛随伯克希尔体量提升）；
2. 已证明的持续盈利能力（不是"困境反转"或概念）；
3. 净资产回报良好且负债很少或没有；
4. 管理层在位（伯克希尔不提供管理）；
5. 业务简单（"如果有大量技术，我们搞不懂"）；
6. 有报价（不想浪费时间谈不确定的交易）。

**承诺**：快速回应（通常5分钟内表态是否有兴趣）、保密、不打探式尽调、现金支付、管理层留任、永久持有。

## E. 出售企业

- 巴菲特对卖家的建议：把企业卖给伯克希尔=卖给一个"永不转手"的家。
- 对卖家最诚实的提醒：大多数收购者（尤其PE）是"商人"——买入就是为了卖出，你的企业会被二次转卖、被杠杆化、被分拆。如果企业的延续性对你重要（员工、品牌、家族传承），买家类型比价格更重要。
- 伯克希尔的差异化定位："有选择的买家"章节的核心卖点——你经营了一辈子的事业，值得一个不折腾它的归宿。

## F. 有选择的买家

- 伯克希尔买什么：家族企业的第二代退出、创始人套现但想保留经营、需要拆分的大集团子公司。
- 经典案例模式（内布拉斯加家具商场B夫人、费希海默、喜诗糖果、波仙珠宝等）：创始人/家族珍惜企业→选择伯克希尔→管理层完全留任→几十年后生意依旧繁荣。
- 交易风格：一页纸协议、握手成交、无投行无审计师军团。"我们进行交易谈判时，卖家完全开诚布公，并且一直干劲十足，效率很高。"

## 投资者视角：如何分析一桩并购公告

| 问题 | 红旗信号 |
|------|---------|
| 用什么支付？ | 被高估的股票/高杠杆举债→买家在透支股东 |
| 付出多少溢价？ | 超30%溢价+模糊协同→动物精神发作 |
| 协同效应可验证吗？ | "1+1>2"但没有具体来源（成本/收入/资本哪一项？） |
| 管理层动机？ | CEO规模崇拜/任期尾声追求"标志性交易" |
| 买家历史记录？ | 过去并购的商誉减值记录=最好的预测指标 |

## 实战启示

1. 作为投资者：所持有公司宣布大并购时，先按上表五问打分，再决定继续持有还是离场。
2. 作为创业者/卖家：买家类型>出价高低。问买家三个问题——你打算持有多久？你打算换管理层吗？你的资金结构能让我安睡吗？
3. 作为管理者：警惕自己的动物精神。每次想收购前，把巴菲特的三动机清单过一遍——兴奋、规模、自信，我中了几个？
