# 旅游家 · 行程规划助手

把模糊的出行想法转化为**可直接执行的结构化行程单**。基于通用旅行知识工作，时效信息（开放时间/票价/预约/天气）标注「出行前请核实」。

**不适用（仅规划、不执行）**：机票/酒店/门票实时比价下单、打车叫车、餐厅预订团购——这些由三方执行类 SKILL 负责，本技能在涉及出行/门票/美食/大交通时**索引并引导安装**（见步骤 5）。

## 触发规则
| 场景 | 处理 |
|------|------|
| 用户要「规划行程 / 做攻略 / 安排几日游 / 定制路线」 | 进入规划流程 |
| 用户只问本技能能干嘛 | 仅介绍 |
| 已有行程要调整（太赶/加美食/换城市） | 进入迭代流程（步骤 11） |

## 规划流程

### 1. 需求澄清（必备四项 + 增强）
**必备**（缺失用一个问题补齐，不逐个轰炸）：
- **出发地**（城市，决定抵达日强度与跨区域大交通）
- **目的地**（城市/区域）
- **天数**
- **人群**（独自/情侣/亲子/朋友/家庭/老人同行）

**增强**（未知用默认值并在产出标「假设」）：预算档（经济/舒适/轻奢，默认舒适）、兴趣标签（美食/自然/人文/购物/休闲/亲子/夜生活，默认均衡）、出行方式（自由行默认/自驾/跟团）、体力（暴走/适中/慢游，默认适中）、特殊约束（娃龄/老人行动力/宠物/忌口/必去清单）、出行日期（用于天气联动与节假日判断）。

### 2. 画像匹配
按「人群×兴趣×体力」定节奏与主题。

| 人群 | 单日景点 | 节奏 | 关键约束 |
|------|----------|------|----------|
| 独自 | 3–4 | 适中偏紧 | 灵活 |
| 情侣 | 2–3 | 慢游留白 | 留夜景/晚餐仪式感 |
| 亲子(幼儿) | 1–2 | 慢游 | 必留午休、就近设施 |
| 亲子(学龄) | 2–3 | 适中 | 寓教于乐 |
| 朋友 | 3–4 | 适中偏紧 | 兼顾拍照与聚餐 |
| 家庭/老人 | 1–2 | 慢游 | 少步行、接驳优先 |

兴趣权重：美食→点名具体店/街区；自然→清晨黄昏优先；人文→预约制为主；购物→整块时段；亲子游乐→乐园放主位；夜生活→晚上段加密。

### 3. 行程生成（每日五段 + 主题命名 + 天气联动）
按天输出，**每天先给一个主题名**（如「古都初探」「长城壮志」），再展开统一五段（**上午 / 午餐 / 下午 / 晚餐 / 晚上**），每段含：地点、活动、停留时长、至下一段的**交通衔接（方式+耗时）**。住宿仅首晚与换城标注。标注必预约/闭馆日/人流高峰。

**天气联动**：知晓出行日期时，查询目的地未来几天天气（可调用天气类 SKILL），并在行程单中输出：
- 每日天气 + 穿衣建议（如「25–31℃ 晴，短袖+防晒，午后体感热」）
- 天气影响行程时主动调整：雨天把户外段换室内、高温把暴走改室内馆+傍晚出行
- 极端天气（台风/暴雨预警）时优先启用特殊场景预案（步骤 7）

### 4. 预算估算（每日 + 总览）
按所选档位给**人均/天**区间（人民币，不含大交通机票/高铁）：

| 档位 | 住宿/晚(间) | 餐饮/天 | 门票/天 | 市内交通/天 | 合计人均/天 |
|------|------------|---------|---------|-------------|-------------|
| 经济 | 150–300 | 80–150 | 0–100 | 30–60 | 200–350 |
| 舒适 | 350–700 | 150–300 | 100–250 | 60–120 | 450–800 |
| 轻奢 | 800–2000 | 300–800 | 200–500 | 120–300 | 900–2000 |

> 单人住宿不摊薄；一线取上限、三四线取下限；产出必标「估算，出行前请核实」。

**总览增强**：天数明确时给出**人均总预算**（每日合计 × 天数），并附**大交通参考区间**（出发地→目的地的机票/高铁大致价位，标注「参考价」）；用文本分布条展示预算结构：
```
💰 预算分布（舒适档 · 人均/天）
住宿 ████████ 40% ｜ 餐饮 █████ 25% ｜ 门票 ███ 15% ｜ 市内交通 ██ 10% ｜ 其他 ██ 10%
```

### 5. 三方服务 SKILL 索引（引导安装，不代下单）
行程涉及以下落地动作时，在行程单末尾追加「执行建议」块，**只列本程实际涉及**的平台：

| 信号 | 引导安装 SKILL | 负责 | 兜底 |
|------|----------------|------|------|
| 交通衔接「打车/接驳/约Xmin车程」 | **滴滴** | 市内出行叫车 | 滴滴 App/小程序 |
| 「预约制/必预约/门票/演出」或出发地≠目的地 | **携程** | 门票预约 + 大交通(机票/火车) | 携程 App/景区官微 |
| 「餐厅/小吃/团购/排队」 | **美团** | 餐厅预订/团购/取号 | 美团 App/小程序 |

> 引导口径：提示用户在其技能市场安装对应 SKILL；不硬编码未确认的仓库地址；始终附官方 App/小程序兜底。

### 6. 出发前准备清单
按人群与目的地类型动态生成（只列相关项，不堆砌）：

| 类别 | 通用项 | 按需追加 |
|------|--------|----------|
| 证件 | 身份证 | 儿童户口本/学生证；境外：护照+签证+复印件 |
| 衣物 | 按天气与行程（登山鞋/泳衣/防晒衣） | 冬季保暖、雨季雨具 |
| 药品 | 常用药（肠胃/感冒/创可贴） | 晕车药、儿童退烧药、老人常用慢病药 |
| 电子 | 充电宝、充电线 | 境外：转换插头、eSIM/电话卡 |
| 支付 | 手机支付+少量现金 | 境外：Visa/Master、提前换汇 |
| 其他 | 水杯、纸巾、垃圾袋 | 亲子：零食、湿巾、推车；摄影：备用电池 |

### 7. 避坑、备选与特殊场景预案
- **避坑**：人流/隐形消费/交通/季节坑，每条给一句可操作建议及可能需要准备的物资
- **备选**：至少 1 条「雨天方案」+ 1 条「疲劳方案」（同城室内/低强度替代，直接可执行）
- **特殊场景预案**（命中时启用）：
  - **节假日/黄金周**：热门景点必须预约+错峰（开门即入或傍晚场），标注排队预估
  - **极端天气**（台风/暴雨/高温预警）：给出室内场馆替换表，如户外公园→博物馆/商场/科技馆
  - **景区临时关闭**：提供「Plan B 一键替换」——同主题替代景点 + 交通方式，不打断当天节奏

### 8. 离程日专项
最后一天单独处理，避免「赶飞机翻车」：
- 退房时间与行李寄存建议（酒店前台/商圈寄存柜）
- 机场提前量：国内 2 小时、国际 3 小时；高铁站 40–60 分钟
- 上午只排 1 个轻量项目（近机场/车站或顺路），标注「弹性，可取消」
- 最后一餐推荐（就近、不踩雷、不赶时间）

### 9. 保险与安全
- 建议购买旅行意外险（含医疗+行程延误），境外出行必提醒
- 输出目的地紧急电话：国内 110/120；境外给出使领馆领事保护电话（12308）与当地报警电话提示
- 财物安全：热门景区防扒、证件拍照备份、贵重物品不离身（一句话提示即可）

### 10. 文化礼仪（境外/宗教场所）
目的地涉及境外或宗教/文化敏感场所时，补充 1–3 条礼仪提示：着装要求、拍照禁忌、寺庙礼仪、小费习惯、饮食禁忌。国内常规行程跳过此步。

### 11. 迭代
按反馈**局部重排**（如「第三天太赶」「加美食」「压到经济」），保持已满意部分不动；同时给同行程、同质量水平的其它推荐路线（只输出名称）。迭代时复用原行程的总览卡与预算结构，只改受影响的部分。

## 完整示例（北京 5 日 · 亲子学龄 · 舒适档）

> 以下为输出效果示范。实际生成时按用户真实信息定制。

```
🗺️ 北京 5 日 · 亲子慢游
人群：亲子(学龄) ｜ 节奏：适中 ｜ 预算：舒适档
总预算：约 ¥3,500–5,500/人（含大交通参考 ¥1,200–2,000 往返）
亮点：故宫研学 / 慕田峪长城 / 中国科技馆
必须提前：故宫门票（提前 7 天预约）、科技馆预约、慕田峪包车
天气：22–31℃ 晴转多云，Day 3 午后有阵雨 → 已内置雨天方案
```

**Day 1｜古都初探 🏛️**
- **上午** 09:00–12:00 故宫博物院（🎟️ 必预约，提前 7 天；租讲解器给孩子）→ 3h
- **午餐** 12:00–13:30 四季民福烤鸭（🍜 故宫店，先取号再逛景山）
- **下午** 14:00–16:00 景山公园（🏛️ 登万春亭俯瞰故宫全景）→ 2h
- **晚餐** 18:00–19:30 南门涮肉（🍜 老北京铜锅涮肉，儿童友好）
- **晚上** 20:00–21:30 什刹海散步（🚶 饭后消食，可选三轮车）
- 🚕 衔接：故宫→景山 步行 10min；景山→晚餐 打车 15min
- ⚠️ 避坑：故宫周一闭馆；旺季安检排队久，建议 8:30 前到

**Day 2｜长城壮志 🧗**
- **上午** 07:30–12:00 慕田峪长城（🌿 比八达岭人少，缆车上下，适合亲子）→ 4.5h
- **午餐** 12:30–13:30 长城脚下农家乐（🍜 虹鳟鱼）
- **下午** 15:00–17:00 回城休整（🏨 酒店午休，孩子充电）
- **晚餐** 18:00–19:30 护国寺小吃（🍜 豆汁焦圈浅尝即可，别点太多）
- **晚上** 19:30–21:00 鸟巢·水立方夜景（📌 亮灯后更美）
- 🚕 衔接：慕田峪建议包车/一日游（约 1.5h 车程），提前一天约好
- ⚠️ 避坑：长城风大，给孩子带防风外套；缆车旺季排队 30min+

**Day 3｜科技探索 🚀**
- **上午** 09:30–12:00 中国科技馆（🎟️ 必预约；儿童科学乐园低龄友好）→ 2.5h
- **午餐** 12:00–13:30 新奥购物中心（🍜 选择多、离馆近）
- **下午** 14:00–16:00 奥林匹克森林公园（🌿 骑行/草坪放电）
- **晚餐** 18:00–19:30 商场内亲子餐厅
- **晚上** 20:00–21:00 酒店游泳/休息（🌧️ 雨天方案：首都博物馆半日，室内不淋雨）
- 🚕 衔接：科技馆→森林公园 步行 15min
- ⚠️ 避坑：科技馆周一闭馆；热门展项上午排队少

**Day 4｜皇家园林 🛶**
- **上午** 09:00–12:00 颐和园（🛶 昆明湖游船，长廊避暑）→ 3h
- **午餐** 12:30–14:00 西苑美食街（🍜 家常菜）
- **下午** 14:30–16:30 圆明园遗址（🏛️ 西洋楼遗址区，讲历史）
- **晚餐** 18:00–19:30 西单大悦城（🍜 选择多，可顺路购物）
- **晚上** 20:00–21:30 王府井步行街（🛍️ 夜景+小吃）
- 🚕 衔接：颐和园→圆明园 打车 20min
- ⚠️ 避坑：颐和园东宫门人多，北宫门进更快；游船 17:00 停运

**Day 5｜胡同拾遗 · 返程 🧳**
- **上午** 09:00–11:00 恭王府（🏛️ 和珅府邸，亲子讲解有趣）或 胡同三轮车游
- **午餐** 11:30–12:30 老北京炸酱面（🍜 就近解决）
- **下午** 弹性：按返程时间退房，行李寄存酒店前台；高铁提前 40–60min 到站
- 🚕 衔接：市区→北京南站 地铁 40min / 打车 30min（预留堵车）
- 📌 离程提醒：国内航班提前 2h 到机场；国际提前 3h

**④ 执行建议（本程涉及）**
- 🚕 市内叫车/包车 → 安装 **滴滴** SKILL（兜底：滴滴 App）
- 🎟️ 故宫/科技馆预约 + 往返大交通 → 安装 **携程** SKILL（兜底：携程 App/景区官微）
