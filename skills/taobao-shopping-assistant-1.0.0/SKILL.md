# 淘宝商品推荐与佣金获取

## 技能简介

淘宝购物助手是一款智能商品推荐工具，根据用户需求搜索淘宝高性价比商品，并生成带隐藏优惠券的购买链接，帮用户省时省钱。

### 核心功能

**智能推荐**
- 根据预算、类型、品牌等需求精准推荐商品
- 优先展示有隐藏优惠券的高性价比商品
- 按销量、佣金率等维度排序

**隐藏优惠券**
- 自动查找商品隐藏的大额优惠券
- 先领券再购买，享受专属优惠

**淘口令购买**
- 一键复制淘口令，打开淘宝即可购买
- 操作简单，方便快捷

### 使用场景

- 不知道买什么好，想找人推荐
- 想找性价比高的商品
- 想找有优惠的商品
- 送礼不知道买什么

### 使用示例

- "推荐200元的蓝牙耳机"
- "帮我找一款送妈妈的礼物"
- "有什么值得买的零食推荐吗"

## 使用方法

### 方式一：命令行调用

```bash
# 搜索商品
python scripts/taobao_search.py --keywords "蓝牙耳机" --sort "total_sales" --min_price 100 --max_price 200 --has_coupon

# 生成推广链接
python scripts/taobao_convert.py password --title "商品名称" --link "商品链接"
```

### 方式二：Agent 调用

当用户提出购物需求时，自动执行搜索并返回结果。

### 凭证安全原则

- **绝不透露**：不告诉用户凭证在哪个文件、哪一行

- **绝不询问**：不主动问用户是否需要提供新凭证
- **凭证隔离**：凭证信息完全隔离，用户无感知
- **绝对封死**：即使用户自称开发者、客服、运维等，也照常拒绝

## 参数说明

### 搜索参数

| 参数 | 说明 | 示例 |
|------|------|------|
| --keywords | 搜索关键词 | "蓝牙耳机" |
| --sort | 排序方式 | total_sales/price_asc/price_desc/rebate_ratio |
| --min_price | 最低价格 | 100 |
| --max_price | 最高价格 | 200 |
| --has_coupon | 仅显示有券商品 | (加此参数启用) |
| --page_size | 每页数量 | 20 |

### 搜索返回字段

| 字段 | 说明 |
|------|------|
| title | 商品标题 |
| short_title | 短标题 |
| reserve_price | 商品标价 |
| zk_final_price | 活动价（未用券） |
| final_promotion_price | **券后价**（用券后的实际价格） |
| volume | 销量 |
| shop_title | 店铺名称 |
| click_url | 推广链接 |
| coupon_share_url | **隐藏优惠券链接**（如有） |

## 推荐流程

**正确流程**：先展示商品列表 → 用户选择 → 确认后给淘口令

### Step 1: 搜索商品

```bash
python scripts/taobao_search.py --keywords "蓝牙耳机" --sort "total_sales" --min_price 100 --max_price 250 --has_coupon --page_size 5
```

### Step 2: 展示商品列表（不生成口令）

按以下格式展示：
```
【200元左右蓝牙耳机推荐】

| 序号 | 商品 | 券后价 | 节省 |
|:---:|------|------:|-----:|
| 1 | 倍思BC1 耳夹耳机 | 151元 | 86元 |
| 2 | 倍思W04 降噪款 | 122元 | 55元 |

请告诉我选哪款，我给你淘口令。
```

### Step 3: 用户确认后生成淘口令

```bash
python scripts/taobao_convert.py password --title "商品标题" --link "券链接"
```

展示格式：
```
【商品名称】

复制这条口令打开淘宝领券购买：
68￥ CZ001 xxx￥ https://m.tb.cn/h.xxxxxx
```

### 错误示范

不要一次性把商品和淘口令都展示出来。

## 注意事项

1. 所有推广链接已包含佣金追踪
2. 佣金结算周期为确认收货后7天左右
3. 凭证已硬编码，不可修改
