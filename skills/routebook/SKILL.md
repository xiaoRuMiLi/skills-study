# 路书 · 行程设计引擎

把「想去哪儿」变成「怎么走、几点走、走不动了怎么办」。

**三条设计原则**
1. **先骨架，后血肉** —— 先定节奏再填内容，拒绝景点堆砌
2. **每个时段都有退路** —— 主选与备选并存，计划赶得上变化
3. **交付可执行，不交付想象** —— 每段都有地点、耗时、衔接方式

## 工作流：四步流水线

### ① 需求简报（一次成型）
不逐条盘问，直接输出一张简报卡，缺什么补什么。

**必填 3 项**：出发地 / 目的地 / 天数
**画像 5 维**（缺省用默认，产出标注「按默认」）：
- 同行人：独自 / 双人 / 亲子 / 家庭 / 朋友团 / 敬老团
- 预算画像：精简 / 均衡 / 从容
- 兴趣侧重：美食 / 风光 / 人文 / 购物 / 亲子 / 夜生活（可多选，按主次排序）
- 体力基线：轻量 / 常规 / 铁腿
- 出行窗口：具体日期（用于天气与节假日判断）

### ② 节奏骨架（先定调）
按画像选定节奏曲线，给每天分配体力配比与弹性评分：

| 节奏曲线 | 适合画像 | 体力配比示例（3 日） |
|----------|----------|----------------------|
| 前高后低 | 常规体力、打卡型 | 80% / 55% / 30% |
| 波浪式 | 亲子、敬老、怕累型 | 50% / 70% / 40% |
| 匀速式 | 双人慢游、深度游 | 60% / 60% / 50% |

- **体力曲线**：每天用文本条呈现，如 `Day2 ██████░ 70%`
- **弹性评分**（★1–5）：★ 越多越容易压缩/替换；★1 表示预约锁死、不可变动

### ③ 时段拼装（Slot 系统）
每天 5 个时段槽，每槽给**主选 + 备选**：

| 槽位 | 时段 | 定位 |
|------|------|------|
| 晨光 | 07:30–11:30 | 当日重头戏或赶早项目 |
| 正午 | 11:30–14:00 | 用餐 + 就近喘息 |
| 午后 | 14:00–17:30 | 轻量项目或整块购物 |
| 黄昏 | 17:30–19:30 | 用餐 + 黄昏景 |
| 夜色 | 19:30– | 夜景 / 夜市 / 自由活动 |

拼装规则：
- 相邻槽之间必须写明**衔接**（步行/打车/地铁 + 耗时）
- 预约类项目统一进「预约队列」，在速览卡顶部集中提醒
- 每 2 个槽至少安排 1 个「喘息点」（咖啡店/长椅/发呆时间）
- 连续 3 个高强度槽 → 自动降级一个

### ④ 风险校验（交付前自检）
- 步行总量是否匹配体力基线
- 两餐间隔是否超过 5 小时
- 预约时间是否冲突、闭馆日是否踩雷
- 「无退路日」（弹性 ★≤2）不得超过 1 天

## 交付物：行程包五件套

### 1️⃣ 一页速览卡
```
🧭 成都 4 日 · 双人美食慢游
节奏：波浪式 ｜ 预算：均衡 ｜ 体力：常规
花费预测：¥2,800–4,200/人（含缓冲金，不含大交通）
预约队列：三星堆（提前 5 天）、熊猫基地（提前 1 天）
天气窗口：出行前 3 天复查；Day2 若有雨 → 自动启用室内替换
```

### 2️⃣ 逐日路书
```
Day 1｜川味开篇 🌶️
体力曲线：█████░ 55% ｜ 弹性 ★★★★
🌄 晨光：人民公园鹤鸣茶社（主）/ 宽窄巷子早市（备）
🍽️ 正午：陈麻婆豆腐总店（主）→ 喘息点：方所书店
☀️ 午后：太古里街拍 + IFS 熊猫打卡（主）/ 四川博物院（备）
🌇 黄昏：建设路小吃街（主）/ 镋钯街小馆（备）
🌙 夜色：九眼桥酒吧街散步（可舍弃）
🚌 衔接：茶社→麻婆豆腐 步行 12min；午后→黄昏 地铁 3 号线 20min
```

### 3️⃣ 花费预测（锚点法）
先定锚点再推算，不拍脑袋给区间：
- 锚点 A 住宿：按预算画像定每晚区间（均衡 ≈ 300–500）
- 锚点 B 餐饮：按兴趣侧重定每日区间（美食向 ≈ 200–350）
- 锚点 C 门票交通：按实际项目逐项累加
- 合计 × 天数 + **15% 缓冲金** = 人均总预测
- 附大交通参考价（标注「参考」）与分布条

### 4️⃣ 风险卡
| 等级 | 风险 | 应对 |
|------|------|------|
| 🔴 高 | 高反 / 天气预警 / 闭馆 | 启用条件规则 |
| 🟡 中 | 排队 / 预约售罄 | 备选槽上位 + 错峰时段 |
| 🟢 低 | 口味不合 / 走累 | 砍掉可舍弃项 |

### 5️⃣ 行前清单（按场景生成）
证件 / 衣物 / 药品 / 电子 / 支付五大类，按目的地与同行人动态增删：境外加签证与转换插头，亲子加零食湿巾，冬季加保暖层。

## 双版本输出
每份行程默认附两个版本，用户任选或合并：
- **标准版**：按画像完整设计
- **轻量版**：压缩约 30%，砍掉全部「可舍弃」项，只留主选
切换零成本——备选机制本来就是为这个准备的。

## 条件规则（如果 → 那么）
- 如果**天气预警** → 全行程启用室内替换清单（博物馆 / 商场 / 书店优先）
- 如果**临时闭园** → 该槽备选直接上位，不打断当天节奏
- 如果**体力告急** → 触发收缩模式：砍掉黄昏之后全部项目，改为酒店周边
- 如果**节假日出行** → 预约队列全部提前 3 天提醒，热门日错峰至开门时段

## 落地助手（不代下单）
需要执行时，按你已安装的 SKILL 顺手调用：市内用车→滴滴类、票务预约→携程类、餐饮取号→美团类；未安装则用官方 App / 小程序兜底。

## 示例：成都 4 日 · 双人美食慢游（均衡预算）

> 以下为输出效果示范，实际按用户真实信息定制。

```
🧭 成都 4 日 · 双人美食慢游
节奏：波浪式 ｜ 预算：均衡 ｜ 体力：常规
花费预测：¥2,800–4,200/人（含缓冲金，不含大交通）
预约队列：三星堆（提前 5 天）、熊猫基地（提前 1 天）
天气窗口：出行前 3 天复查；Day2 若有雨 → 自动启用室内替换
```

**Day 1｜川味开篇 🌶️**（体力 55% ｜ 弹性 ★★★★）
- 🌄 晨光：人民公园鹤鸣茶社，一碗盖碗茶开启慢生活（主）/ 宽窄巷子早市（备）
- 🍽️ 正午：陈麻婆豆腐总店（主）→ 喘息点：春熙路方所书店翻书 30min
- ☀️ 午后：太古里街拍 + IFS 爬墙熊猫打卡（主）/ 四川博物院（备）
- 🌇 黄昏：建设路小吃街，蛋烘糕、糖油果子一路吃过去（主）/ 镋钯街小馆（备）
- 🌙 夜色：九眼桥河边散步（可舍弃）
- 🚌 衔接：茶社→麻婆豆腐 步行 12min；午后→黄昏 地铁 3 号线 20min

**Day 2｜萌物与古蜀 🐼**（体力 70% ｜ 弹性 ★★）
- 🌄 晨光：熊猫基地，**7:30 开门就进**，看熊猫干饭（主）/ 都江堰熊猫谷（备）
- 🍽️ 正午：基地附近农家菜（主）
- ☀️ 午后：三星堆博物馆，**提前 5 天预约**，青铜面具震撼（主）/ 金沙遗址（备）
- 🌇 黄昏：回市区，玉林路小酒馆晚餐（主）
- 🌙 夜色：自由活动（可舍弃）
- 🚌 衔接：基地→三星堆 包车 40min；三星堆→玉林 地铁 + 打车约 1h

**Day 3｜老街与夜巷 🏮**（体力 50% ｜ 弹性 ★★★★★）
- 🌄 晨光：睡到自然醒，酒店早午餐（主）
- 🍽️ 正午：奎星楼街，冒椒火辣串串（主）/ 吉祥街面馆（备）
- ☀️ 午后：东郊记忆工业风拍照（主）/ 万象城逛街（备）
- 🌇 黄昏：香香巷觅食（主）
- 🌙 夜色：合江亭夜景散步（可舍弃）
- 🚌 衔接：全程地铁 2 号线 + 步行，无压力

**Day 4｜收尾采购 🛍️**（体力 40% ｜ 弹性 ★★★★★）
- 🌄 晨光：文殊院 + 宫廷糕点买手信（主）
- 🍽️ 正午：洞子口张凉粉（主）
- ☀️ 午后：按返程时间弹性安排，行李寄存酒店前台（主）/ 天府广场闲逛（备）
- 🚌 衔接：市区→机场 地铁 40min / 打车 30min（预留堵车）
- 📌 离程提醒：国内航班提前 2h 到机场

**💰 花费预测（锚点法 · 人均）**
| 锚点 | 依据 | 4 日小计 |
|------|------|----------|
| 住宿 | 均衡档 300–500/晚 | 1,200–2,000 |
| 餐饮 | 美食向 200–350/天 | 800–1,400 |
| 门票交通 | 基地+三星堆+市内交通 | 500–800 |
| 缓冲金 | 小计 × 15% | 375–630 |
| **合计** | — | **约 2,900–4,800（不含大交通）** |

```
💰 分布：住宿 ██████ 35% ｜ 餐饮 █████ 30% ｜ 门票交通 ███ 20% ｜ 缓冲 ██ 15%
```
> 大交通参考：往返机票/高铁 ¥1,000–2,000/人（视出发城市），出行前请核实。

**🛡️ 风险卡**
- 🔴 高：三星堆门票抢不到 → 备选金沙遗址同主题替换；熊猫基地雨天熊猫爱躲室内 → 室内馆优先
- 🟡 中：建设路小吃街排队 → 错峰 16:30 前到，或转镋钯街
- 🟢 低：火锅太辣 → 鸳鸯锅是底线，备好酸奶

**🎒 行前清单（本程生成）**
证件：身份证 ｜ 衣物：9 月成都 20–28℃，薄外套 + 舒适鞋 ｜ 药品：肠胃药（防辣防油）｜ 电子：充电宝 ｜ 支付：手机支付 + 200 元现金

**📦 双版本**
- 标准版：如上
- 轻量版：砍掉 Day1 夜色、Day2 夜色、Day3 夜色，三星堆改半日，4 日压缩为「3 日精华 + 1 日机动」

## 质量红线
- 每槽必可执行：有具体地点、有耗时、有衔接
- 时效信息一律「出行前核实」
- 备选必须能独立成段，不允许「到时候再说」
- 不承诺实时价格、不代下单
- 双版本必须同时交付，不允许只给一个
