## 二、教学目标表述对照表

| 认知层次 | 可测行为动词 | 三维目标归属 | 素养表述示例 |
|---|---|---|---|
| 记忆 | 说出、写出、列举、背诵、辨认 | 知识与技能 | 能准确说出……的定义/要素 |
| 理解 | 解释、概括、举例、转述、比较 | 知识与技能 | 能用自己的话解释……的成因 |
| 应用 | 计算、运用、演示、操作、解决 | 过程与方法 | 能运用……解决……类问题 |
| 分析 | 区分、归类、推断、找出关系 | 过程与方法 | 能分析……与……之间的联系 |
| 评价 | 评述、判断、鉴赏、质疑 | 情感态度价值观 | 能对……作出有依据的评价 |
| 创造 | 设计、改写、提出方案、创作 | 过程与方法+情感 | 能设计……的改进方案 |

写目标的三段式公式：**行为条件（通过/借助/在……中）+ 行为动词 + 表现程度（准确/初步/至少三点）**。
反例：「了解背影的写作背景」→ 改写：「通过阅读背景资料卡，能用两句话概括《背影》的写作背景及其对理解父子情感的作用」。

## 三、各学段差异要点

- **小学**：环节要短频快（单环节不超过 8 分钟），活动游戏化；目标动词更外显（圈一圈、摆一摆、演一演）；板书多用图形符号；作业以实践性、口头性为主，低年级不留书面家庭作业。
- **初中**：开始强调证据意识与方法归纳；导入可用认知冲突；小组合作要给明确分工单；作业分层必须落实。
- **高中**：突出大概念统摄与深度学习；教学过程可采用「问题链 + 学习任务单」双线结构；目标直接对接学科核心素养与学业质量水平（水平 1-4/1-5）；作业可含小论文、建模报告等表现性任务。

## 四、分学科教案侧重点

### 语文
- 主线：文本细读线 + 情感/思辨线双线并行。新授课常用结构：初读感知（整体把握）→ 精读品析（抓关键词句，批注式阅读）→ 深读探究（主旨/写法）→ 读写迁移。
- 目标必须落到具体语言现象上（某个词、某处标点、某种句式），忌空谈「体会情感」。
- 部编版语文注意「双线组元」：人文主题 + 语文要素，教材分析中要点明本单元语文要素并在环节中落实。
- 板书常用「鱼骨图/情感曲线图/关键词辐射图」。

### 数学
- 主线：问题情境 → 抽象建模 → 探究算理/推理证明 → 变式应用 → 归纳结构。
- 重点写清「算理与算法并重」：不仅会算，还要能说清为什么这样算。
- 探究环节设计「操作—猜想—验证—结论」完整闭环；准备好脚手架问题（学生卡壳时逐级提示）。
- 例题—变式题—拓展题的梯度要在教案中显式呈现（改条件、改问法、改情境三种变式手法）。

### 英语
- 采用「英语学习活动观」三层活动设计：学习理解（感知与注意、获取与梳理）→ 应用实践（描述阐释、内化运用）→ 迁移创新（推理论证、想象创造）。
- 以语篇为依托：教材分析需含语篇类型（what/why/how 三问：主题内容、写作意图、文体语言特征）。
- 阅读课典型结构：Pre-reading（预测激活）→ While-reading（略读找主旨 + 细读找细节 + 深读析态度）→ Post-reading（输出任务：复述/采访/写作）。
- 词汇语法不单列讲授，融入语境；教案中注明关键指令语（classroom English）。

### 物理/化学/生物（理科通用）
- 实验探究课八环节：提出问题 → 猜想假设 → 设计方案 → 进行实验 → 收集证据 → 分析论证 → 评估交流 → 得出结论；教案中写明分组器材单与安全提示。
- 概念课重「前概念转化」：学情分析必须写出学生的典型迷思概念（如「重的物体下落快」），并设计认知冲突实验予以转化。
- 化学注意实验安全红线与规范操作表述；生物注意结构与功能观、稳态与平衡观等学科观念的显性渗透。

### 历史/地理/道德与法治（文综通用）
- 历史：史料实证是核心环节，每课至少 2 则史料（注明出处类型：一手/二手），设计「读史料—提信息—作解释」任务链；时空定位用时间轴/地图开场。
- 地理：坚持「图导图学」，每环节挂图（区域图/统计图/示意图）；突出人地关系主线与区域认知方法（在哪里→有什么→为什么→怎么办）。
- 道德与法治：议题式教学，设置真实两难情境展开思辨；注意价值引领的落点必须自然，忌贴标签式升华。

## 五、常见检查扣分点自查表

1. 目标动词不可测（了解/掌握满篇）→ 换用对照表动词。
2. 设计意图缺失或与目标脱节 → 每环节意图末尾加「（落实目标 X）」。
3. 只有教师活动没有学生活动 → 学生活动写到「做什么、说什么、产出什么」。
4. 重难点与教学过程脱节 → 难点突破环节需明确标注。
5. 板书设计缺失或为空 → 至少给出结构示意。
6. 作业无分层、无时长 → 三层 + 时长 + 目标对应。
7. 课时容量超载（一节课塞 5 个环节 8 个任务）→ 新授课核心任务不超过 3 个。
